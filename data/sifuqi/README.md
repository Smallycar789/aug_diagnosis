# 伺服控制精度退化仿真

## 概述

二自由度云台直流伺服控制系统在长期运行下的精度退化仿真。模拟电机参数变化 + PID 控制 + 多源噪声下的性能衰退。

## 科学模型

### 电机模型

```
V = R·i + L·di/dt + Kb·ω        (电气方程)
J·dω/dt = Kt·i - B·ω - Tf·sign(ω)  (机械方程)
```

| 参数 | 含义 | 正常值(方位轴) | 单位 |
|------|------|-------------|------|
| R | 绕组电阻 | 2.50 | Ω |
| Kt | 力矩常数 | 0.450 | N·m/A |
| Kb | 反电势常数 | 0.450 | V·s/rad |
| J | 转动惯量 | 0.004 | kg·m² |
| B | 阻尼系数 | 0.0008 | N·m·s/rad |
| Tf | 库仑摩擦 | 0.003 | N·m |

### 退化规律

| 参数 | 公式 | 物理机制 |
|------|------|---------|
| R(t) | R₀·(1 + α·t) | 绕组热老化，线性增长 |
| Kt(t) | Kt₀·exp(-β·t) | 永磁体退磁，指数衰减 |
| B(t) | B₀·(1 + γ·t^1.5) | 轴承磨损，加速增长 |
| Tf(t) | Tf₀ + ΔTf·(1 - e^(-λt)) | 摩擦增大，指数趋近 |

### 控制器（位置环 P + 速度环 PI）

```
vel_cmd = Kp_pos · (θ_cmd - θ_actual)
i_cmd   = Kp_vel · vel_err + Ki_vel · ∫ vel_err dt
```

| 参数 | 方位轴 | 俯仰轴 |
|------|--------|--------|
| Kp_pos | 25 | 20 |
| Kp_vel | 5.0 | 4.0 |
| Ki_vel | 20 | 16 |

### 噪声模型

| 类型 | 来源 | 量级 |
|------|------|------|
| 量化噪声 | 18-bit 编码器 | σ ≈ 0.000087° |
| 热噪声 | √(4·kB·T·R·BW) | μdeg 级 |
| 1/f 闪烁 | 电子器件 | 低频累积 |
| 工频干扰 | 50Hz 电网 | ~0.0005° |
| 脉冲噪声 | 偶发 EMI | 随机尖峰 |

### 误差理论公式

```
e_track = A · ω_cmd / Kp_pos      (闭环跟踪误差, 位置环比例控制)
e_ss    = Tf_deg / Kp_pos          (稳态误差, 库仑摩擦 / 位置刚度)
```

## 退化等级

| 等级 | 运行时长 | R(Ω) | Kt | Tf | 稳态误差 | 跟踪误差 |
|------|---------|------|-----|------|---------|---------|
| 正常 | 0 h | 2.50 | 0.450 | 0.003 | ~0.09° | ~0.43° |
| 轻度 | 600 h | 2.73 | 0.442 | 0.013 | ~0.10° | ~0.47° |
| 中度 | 1800 h | 4.30 | 0.390 | 0.043 | ~0.14° | ~0.60° |
| 重度 | 3500 h | 10.38 | 0.240 | 0.103 | ~0.15° | ~0.62° |

## CSV 列定义

| 列 | 字段 | 单位 | 说明 |
|----|------|------|------|
| 1 | timestamp | s | 时间 |
| 2 | azimuth_cmd | deg | 方位角指令值 |
| 3 | azimuth_actual | deg | 方位角实际值 |
| 4 | azimuth_error | deg | 方位角跟踪误差 |
| 5 | pitch_cmd | deg | 俯仰角指令值 |
| 6 | pitch_actual | deg | 俯仰角实际值 |
| 7 | pitch_error | deg | 俯仰角跟踪误差 |
| 8 | azimuth_current | A | 方位电机电流 |
| 9 | pitch_current | A | 俯仰电机电流 |
| 10 | temperature | °C | 温度 |
| 11 | vibration | g | 振动加速度 |
| 12 | mtf | ratio | 调制传递函数 |
| 13 | label | - | normal / degraded |

## 每张大图 6 子图内容

| 位置 | 内容 |
|------|------|
| 左上 | 指令 vs 实际（方位+俯仰 4线, 前10s） |
| 右上 | 跟踪误差全时域（方位+俯仰） |
| 左中 | 电机电流（方位+俯仰, 前15s） |
| 右中 | 温度曲线 |
| 左下 | 振动信号 |
| 右下 | MTF 曲线 + 指标摘要表 |

## 使用方式

```bash
# 创建环境（首次）
conda env create -f environment.yml
conda activate servo_sim

# 生成数据
python generate.py

# 生成图表
python plot_per_level.py
```
