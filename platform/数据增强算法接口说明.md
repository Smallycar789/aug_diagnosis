# 数据增强算法接口说明

版本：V1.1  
运行环境：Python 3.7.6（`platform/requirements-py37.txt`）  
总览文档：[platform/README.md](README.md)

---

## 1. 服务一览

| 脚本 | 函数 | 何时使用 |
|------|------|----------|
| `platform/data_augmentation_train.py` | `data_augmentation_train` | 需要**重新训练**生成模型 |
| `platform/data_augmentation_generate.py` | `data_augmentation_generate` | 对**已有模型**生成样本（常用） |

底层实现：`data_aug/train.py` → `data_aug/gan.py`、`data_aug/tvae.py`、`data_aug/gan_vae.py`。

---

## 2. 生成接口 `data_augmentation_generate`（优先对接）

### 2.1 run_dir 要求（必读）

`run_dir` 必须指向 **`outputs/data_aug/` 下的正式实验目录**，例如：

```
outputs/data_aug/sensitivity/gan/_gan_sensitivity_2feat_l96_v1
```

目录内须包含：

| 文件 | 说明 |
|------|------|
| `checkpoint_best.pth` | 生成模型权重 |
| `config_resolved.yaml` | 训练配置 |

生成结果会写入**同一目录**（`generated_*.npy` 等）。

### 2.2 调用

```bash
cd /path/to/aug_diagnosis
python platform/data_augmentation_generate.py --config platform/configs/data_augmentation_generate_input.json
```

在 JSON 中设置 `run_dir` 为 `outputs/data_aug/...` 下的实际路径。

### 2.3 输入参数

| 英文名 | 类型 | 说明 |
|--------|------|------|
| run_dir | str | `outputs/data_aug/` 下实验目录 |
| algorithm | str | 可选标识：`gan` / `tvae` / `gan_vae` |
| platform_output_json_file | str | 可选 |

### 2.4 返回字段

| 英文名 | 说明 |
|--------|------|
| status | 执行状态 |
| output_dir | 与 run_dir 相同 |
| num_generated | 生成样本数 |
| generated_files | `.npy` 文件路径列表 |
| metrics | 评估指标详情（数值统计，不含对比图/频谱图等图片路径） |

典型输出文件：`generated_{class}.npy`、`generated_samples.npy`、`norm_params.json`。

## 3. 训练接口 `data_augmentation_train`

仅在需要重新训练时使用。完整训练将 `smoke` 设为 `false`。

### 3.1 调用

```bash
python platform/data_augmentation_train.py --config platform/configs/data_augmentation_train_input.json
```

结果写入 **`outputs/data_aug/`**。

### 3.2 输入参数

| 英文名 | 类型 | 说明 | 默认值 |
|--------|------|------|--------|
| data_dir | str | CSV 数据根目录 | 空 |
| dataset_profile | str | `sensitivity` / `cooler` / `sifuqi` | sensitivity |
| algorithm | str | `gan` / `tvae` / `gan_vae` | tvae |
| device | str | `auto` / `cpu` / `cuda` | auto |
| smoke | bool | `true` 联调；正式训练 `false` | true |
| platform_output_json_file | str | 可选 | 空 |

### 3.3 返回字段

| 英文名 | 说明 |
|--------|------|
| status | 执行状态 |
| output_dir | `outputs/data_aug/...` 下新目录 |
| checkpoint_path | `checkpoint_best.pth` |
| config_path | 临时 YAML（`platform/runtime/`） |

训练完成后，用 `output_dir` 作为 `data_augmentation_generate` 的 `run_dir`。

## 4. 算法与 outputs 目录对应关系

| algorithm | 典型 outputs 路径 |
|-----------|-------------------|
| gan | `outputs/data_aug/{dataset}/gan/{实验名}/` |
| tvae | `outputs/data_aug/{dataset}/tvae/{实验名}/` |
| gan_vae | `outputs/data_aug/{dataset}/gan_vae/{实验名}/` |
