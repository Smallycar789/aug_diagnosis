# 故障诊断算法接口说明

版本：V1.1  
运行环境：Python 3.7.6（`platform/requirements-py37.txt`）  
总览文档：[platform/README.md](README.md)

---

## 1. 服务一览

| 脚本 | 函数 | 何时使用 |
|------|------|----------|
| `platform/fault_diagnosis_train.py` | `fault_diagnosis_train` | 需要**重新训练**诊断模型 |
| `platform/fault_diagnosis_test.py` | `fault_diagnosis_test` | 对**已有模型**做测试评估（常用） |

底层实现：`diagnosis/train.py`、`diagnosis/test.py` → `diagnosis/cnn_bigru.py` 等。

---

## 2. 测试接口 `fault_diagnosis_test`（优先对接）

平台组装时，通常直接加载 `outputs/` 下已训练好的模型，**无需重新训练**。

### 2.1 run_dir 要求（必读）

`run_dir` 必须指向 **`outputs/diagnosis/` 下的正式实验目录**，例如：

```
outputs/diagnosis/sensitivity/cnn_bigru/cnn_bigru_sensitivity_v1_20260526_152138
```

目录内须包含：

| 文件 | 说明 |
|------|------|
| `checkpoint_best.pth` | 模型权重 |
| `config_resolved.yaml` | 训练时的完整配置 |

**不要**使用 `platform/runtime/` 或冒烟训练（`smoke=true`）产生的目录作为交付测试对象。

### 2.2 调用

```bash
cd /path/to/aug_diagnosis
python platform/fault_diagnosis_test.py --config platform/configs/fault_diagnosis_test_input.json
```

修改 `platform/configs/fault_diagnosis_test_input.json` 中的 `run_dir`：

```json
{
  "english_name": "run_dir",
  "param_value": "outputs/diagnosis/sensitivity/cnn_bigru/cnn_bigru_sensitivity_v1_20260526_152138"
}
```

### 2.3 输入参数

| 英文名 | 类型 | 说明 | 默认值 |
|--------|------|------|--------|
| run_dir | str | `outputs/` 下实验目录（见上） | — |
| split | str | `test` 或 `val` | test |
| platform_output_json_file | str | 可选，写出 output JSON | 空 |

### 2.4 返回字段

| 英文名 | 说明 |
|--------|------|
| status | `success` / `failed` |
| output_dir | 与 run_dir 相同 |
| accuracy | 测试准确率 |
| f1_macro | 宏平均 F1 |
| metrics | 测试指标详情（数值与分类报告，不含图片路径） |
| confusion_matrix_png | 故障诊断混淆矩阵图路径 |
| error_message | 失败描述 |

## 3. 训练接口 `fault_diagnosis_train`

仅在需要重新训练或验证训练链路时使用。完整训练请将 `smoke` 设为 `false`。

### 3.1 调用

```bash
python platform/fault_diagnosis_train.py --config platform/configs/fault_diagnosis_train_input.json
```

训练结果写入 **`outputs/diagnosis/`**（与算法层 `diagnosis/train.py` 一致），不是 `platform/` 下。

### 3.2 输入参数

| 英文名 | 类型 | 说明 | 默认值 |
|--------|------|------|--------|
| data_dir | str | CSV 数据根目录；空则按 profile 解析 | 空 |
| dataset_profile | str | `sensitivity` / `cooler` / `sifuqi` | sensitivity |
| algorithm | str | `cnn_bigru` / `resnet` / `tl_meta` | cnn_bigru |
| device | str | `auto` / `cpu` / `cuda` | auto |
| smoke | bool | `true` 仅 2 epoch 联调；正式训练用 `false` | true |
| platform_output_json_file | str | 可选 | 空 |

`data_dir` 示例：

- 正式数据：`data/degradation/`（sensitivity 类文件）或 `data/cooler/` 等
- 联调小数据：`platform/demo_data/sensitivity`

### 3.3 返回字段

| 英文名 | 说明 |
|--------|------|
| status | 执行状态 |
| output_dir | 新训练目录（在 `outputs/diagnosis/...` 下） |
| checkpoint_path | `checkpoint_best.pth` |
| config_path | 本次生成的临时 YAML（`platform/runtime/`） |
| algorithm / dataset_profile | 算法与数据集标识 |

训练完成后，用返回的 `output_dir` 作为 `fault_diagnosis_test` 的 `run_dir`。

## 4. 算法与 outputs 目录对应关系

| algorithm | 典型 outputs 路径 |
|-----------|-------------------|
| cnn_bigru | `outputs/diagnosis/{dataset}/cnn_bigru/{实验名}/` |
| resnet | `outputs/diagnosis/{dataset}/resnet/{实验名}/` |
| tl_meta | `outputs/diagnosis/{dataset}/tl_meta/{实验名}/` |

`{dataset}` 可为 `sensitivity`、`cooler`、`sifuqi`、`image_quality` 等。

## 6. ResNet 离线预训练（验收机）

ResNet 训练在 `diagnosis/resnet.py` 的 `build_tl_resnet18()` 中初始化骨干网络。无网环境下按 `dataset.name` 自动加载：

`references/diagnosis/pretrained/resnet_{dataset}.pth`

- **训练 / 平台训练**：命令与 JSON 接口不变；本地文件存在时不访问 ImageNet。
- **测试 / 平台测试**：`run_dir` 仍指向 `outputs/diagnosis/.../` 下含 `checkpoint_best.pth` 的实验目录，与改前一致。
- **交付清单**：除 `outputs/` 中训练好的模型外，验收包需自带上述四个 `.pth`（仓库路径 `references/diagnosis/pretrained/`）。
- **重新生成**：有网环境执行 `python scripts/export_resnet_pretrained_init.py`。

详见 `FRAMEWORK_DESIGN.md` §5.3 与 `diagnosis/README.md`。
